# Cuatro tareas reales

Material de taller del seminario **Liderazgo educativo potenciado por la IA**
(Universidad San Sebastián), a partir del libro *El Director LIBRE*
(Banco Mundial).

Cuatro casos de dirección escolar, cada uno pedido dos veces a una IA: una como
se pide de apuro y otra con las cuatro partes de la llave maestra. Los dos
pedidos reciben **exactamente el mismo material**, así que lo único distinto son
las palabras del pedido.

Las respuestas que muestra la página son las que volvieron de verdad, pedidas
por API a claude-opus-5 el 15 de octubre de 2026, sin instrucciones previas.
Están completas y sin editar.

El material que recibe la IA (los informes, los documentos de álgebra, las notas
de observación y la planilla) está escrito para el taller y va marcado como
ejemplo. Ningún dato corresponde a una escuela real.

La página está construida sobre el artifact de María Andreina Cantele
(Banco Mundial), con sus mismos componentes.
